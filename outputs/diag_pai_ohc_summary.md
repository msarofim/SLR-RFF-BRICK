# Does OHC carry the Antarctic time-component? (17 models)

ΔT_ant ~ α·ΔGMST (M1) vs α·ΔGMST + β·ΔOHC (M2); OHC = zostoga; pooled over 1pctCO2 + abrupt-4xCO2, ΔGMST >= 1.0 K, anomalies rel. piControl.

- pooled R2 (median): M1 0.942, M2 0.954
- **between-experiment residual bias |median|: M1 0.105 K -> M2 0.091 K** (the DECK age effect GMST-only cannot fit; OHC removes it)
- transfer RMSE (fit abrupt, predict 1pct), median: M1 0.983 K -> M2 0.580 K
- β_OHC > 0 in 17/17 models

Models: ACCESS-CM2, ACCESS-ESM1-5, BCC-CSM2-MR, CMCC-CM2-SR5, CNRM-CM6-1, CNRM-CM6-1-HR, CNRM-ESM2-1, CanESM5, EC-Earth3-AerChem, EC-Earth3-Veg, GISS-E2-1-G, GISS-E2-1-H, IPSL-CM6A-LR, MPI-ESM1-2-HR, MPI-ESM1-2-LR, MRI-ESM2-0, UKESM1-0-LL
