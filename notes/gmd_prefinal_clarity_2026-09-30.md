# Ladrillo v1.0 GMD draft: clarity and submission-readiness review (read-only)

Line numbers refer to m.txt. GMD rules come from the manuscript_types, submission and code-and-data-policy pages, fetched 2026-09-30.

## MUST fix before sharing

1. **Required sections are missing.** There is no "Author contributions" section (mandatory, placed before Acknowledgements), no Financial support section, and no corresponding-author email on the title page. If AI tools were used, GMD asks for a disclosure in Methods or Acknowledgements.
2. **Code availability (L282) is incomplete.** The DOI placeholder is known, but "[repository URL]" is a second placeholder. The licence appears only in the Conclusions (L276); it should also go here. MimiBRICK is cited by its GitHub URL, which the GMD policy says is "not suitable" as an archive, so give a v2.0.0 Zenodo DOI. Rennels et al. (2022) is the "all versions" DOI; use the DOI for Mimi 1.6. GMD also requires a user manual, which can live in the archive; say where it is.
3. **Scenario codes are never defined.** vvLN and vvML (L250, L268, L270) and vvVL (L266) are never defined. "High", "Very Low" and "High-to-Low" are used from L17 onward, but the seven marker scenarios are never listed. Add one sentence or a table at L230 that maps each code to its name.
4. **SSP results appear with no source.** SSP1-2.6, SSP2-4.5 and SSP5-8.5 numbers appear at L94, L96, L108 and L274, but only the van Vuuren runs are described. L264 quotes "widths of 314 and 405 cm at SSP5-8.5" inside the High-scenario paragraph.
5. **The projection baseline is never stated.** Hindcasts use 1995–2005. "relative to 1995–2014" (L116) and the FACTS sentence "treated as comparable to the 1995–2014 mean" (L232) imply a second baseline. State both explicitly.
6. **Internal and code language is still in the text:**
   - "Ladrillo L27" (L178, figure placeholder)
   - "SLOWG = SLOWP and FASTG = FAST in the code" (L301)
   - "ledger terms" (L335)
   - "generated by the calibrator itself … not transcribed" (L294)
   - "deliverable-level criterion" (L170)
   - "arm" / "joint arm" / "fixed-climate arm" (L116, L172, L230, L250), never defined
   - "same cubes, splice pivot, and pair seed" (L230)
   - "in every calibration that sampled them" (L106)
   - "antarctic_lambda" and "ais_iceflow0" in running text (L264, L168)
7. **Typo:** "the Greenland peripher not included in Ladrillo" (L135).
8. **Figure and table order.** Figs. 2, 3, 4 and 6 are never cited in the text; only their captions mention them. Fig. 5 is first cited at L82, before Fig. 1. Table 4 is cited at L102 before Table 3 has any in-text citation. Table 5 appears (L208) before its first citation (L222).
9. **Numbers that do not match:**
   - Conclusions say "changes of up to 31 cm by 2300" (L274), but L108 says 32 cm. Check which quantity each refers to.
   - Conclusions mention "regrowth … in the short-timescale regional block" (L274), but the Results never say which block regrows.
10. **The model cannot be re-implemented from the paper (a core GMD criterion).**
    - The Greenland two-basin/two-channel scheme, the above-threshold channel, the regional-temperature driver and the AR(1) likelihood are described in prose only.
    - The Table A1 parameters gis_c0, gis_f and gis_slow_ell/_w are never tied to equations.
    - The fixed values (V = 564 cm, τ = 800 yr, 4.69 K, λ/T_crit/γ) are not tabulated.
    - The glacier equation (L79–80) leaves T_eq, ν, κ and the time step undefined, and "equilibrium volume S_eq" (L65) conflicts with "Committed-loss scale a" in Table A1.
    - There is no verification subsection. GMD asks for verification to be separated from evaluation; for example, show that reverted components reproduce BRICK 2.0.

  - Drop the colons in "Results:" and "Conclusions:".
